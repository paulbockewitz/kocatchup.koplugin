# Vendored KOReader code

`pluginloader.lua` is copied unmodified from [koreader/koreader](https://github.com/koreader/koreader) (`frontend/pluginloader.lua`, AGPL-3.0) and is used **only** by `spec/smoke_pluginloader.lua` to verify plugin discovery and loading against KOReader's real loader. It is not part of the shipped plugin.
